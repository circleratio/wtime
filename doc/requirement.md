# 概要
- CLIの時刻表示ツール（世界時計）。実装言語はPython。

# 要求仕様
- 引数なしで実行した場合、現在のローカルタイムを表示する
- 引数にタイムゾーン（IANA tzデータベース名、例: `Europe/London`）を1つ以上指定すると、ローカルタイムに加えて指定した各タイムゾーンの現在時刻を1行ずつ出力する
- タイムゾーンは複数同時に指定できる
- タイムゾーン引数は、IANA名の都市部分（最後のセグメント。例: `Asia/Tokyo` の `Tokyo`）だけの指定も受け付ける（`/` を含まない入力のみが対象。`/` を含む入力は従来通り完全なIANA名として扱う）
  - 都市名の照合は完全一致のみで、大文字小文字は区別しない（例: `Tokyo`・`tokyo`・`TOKYO` はいずれも `Asia/Tokyo` に解決される）
  - アンダースコア入りの都市名（例: `Los_Angeles`）は、アンダースコアの代わりにスペースで指定してもよい（例: `"Los Angeles"`。シェル上ではクォートが必要）
  - 同じ都市名が複数のタイムゾーンにマッチする場合は曖昧な指定としてエラーとし、該当する候補（IANA名一覧）をエラーメッセージに含める
  - 一致するタイムゾーンが1つもない場合は、既存の「存在しないタイムゾーン名」と同様にエラーとする
- 出力フォーマットは `YYYY-MM-DD(曜日) HH:MM:SS ±HH:MM タイムゾーン名` とする（例: `2026-08-25(Tue) 14:30:00 +09:00 Asia/Tokyo`）
- 存在しないタイムゾーン名が指定された場合は、標準エラー出力にエラーメッセージを出力し、非ゼロの終了コードで終了する
- `--help` オプションで使いかたを表示する
- `--version` オプションでバージョン番号を表示する
- `--diff` オプションを指定すると、指定した各タイムゾーンの出力行の末尾に、その行の時刻とローカル時刻との時間差を追記する
  - ローカルタイムの行自体には時間差を付けない（差分は必ず0のため）
  - 時間差の表記形式は符号付き（`+`/`-`）で、時間単位を基本とし、分単位の差がある場合のみ分も表示する（例: `+9h`、`-8h`、`+5h30m`、`-3h45m`）
  - 符号は「指定タイムゾーンの時刻がローカル時刻よりどれだけ進んでいるか」を表す（対象のUTCオフセット − ローカルのUTCオフセット）。進んでいれば`+`、遅れていれば`-`
  - タイムゾーンを1つも指定せずに `--diff` のみを指定した場合は、通常通りローカル時刻の1行のみを表示する（エラーにはしない）
- `--time <日時>` オプションを指定すると、現在時刻の代わりに指定した日時をローカルの基準時刻として扱い、通常の時刻表示および `--diff` の時間差計算を行う
  - `<日時>` は「ローカル」のタイムゾーン（後述の `--set-local-tz` が指定されていればそのタイムゾーン、指定されていなければマシンのシステムタイムゾーン）の日時として解釈する
  - 入力フォーマットは `YYYY-MM-DDTHH:MM[:SS]`（T区切り）または `YYYY-MM-DD HH:MM[:SS]`（スペース区切り、シェル上ではクォートが必要）のいずれも受け付ける
  - 秒は省略可能で、省略時は00秒として扱う。日付のみの指定（時:分の省略）は不可とする
  - `--time` を指定してもローカル行は `(ローカル)` 表記のまま変わらない（表す時刻が「現在」から「指定日時」に変わるだけ）
  - 不正な形式の日時が指定された場合は、標準エラー出力にエラーメッセージを出力し、非ゼロの終了コードで終了する（`--diff`の不正なタイムゾーン名と同様、通常出力は行わない）
- `--set-local-tz <タイムゾーン>` オプションを指定すると、コマンドを実行したマシンのシステムタイムゾーンの代わりに、指定したタイムゾーンを「ローカル」として扱う
  - `<タイムゾーン>` の指定形式は通常のタイムゾーン引数と同じで、フルのIANA名・都市名だけの指定のどちらも受け付ける（都市名の解決ルールも同一。曖昧な場合はエラーとし候補を提示する）
  - `--set-local-tz` を指定すると、出力の「ローカル」行（`(ローカル)` と表示される行）は、マシンの実際のタイムゾーンではなく指定したタイムゾーンの時刻を表示する
  - `--diff` は、指定したタイムゾーンを基準（差分0）として各タイムゾーンとの時間差を計算する
  - `--time` と併用した場合、`--time` に渡した日時は `--set-local-tz` で指定したタイムゾーンの壁時計時刻として解釈される
  - `<タイムゾーン>` が不正・存在しない・複数のタイムゾーンに曖昧に一致する場合は、通常のタイムゾーン引数と同様にエラーメッセージを出力し、非ゼロの終了コードで終了する（通常出力は行わない）

# 使いかた
## 引数なし
```
wtime
=> 現在のローカルタイムの時刻を表示
```

## タイムゾーンを引数に指定
```
wtime Europe/London
=> 現在のローカルタイムの時刻、指定されたタイムゾーンの時刻を一行ずつ出力
```

## 複数のタイムゾーンを引数に指定
```
wtime Europe/London Asia/Tokyo
=> 現在のローカルタイムの時刻に加え、指定した各タイムゾーンの時刻を一行ずつ出力
```

## 出力例
```
$ wtime Europe/London Asia/Tokyo
2026-08-25(Tue) 14:30:00 +09:00 Asia/Tokyo (ローカル)
2026-08-25(Tue) 06:30:00 +01:00 Europe/London
2026-08-25(Tue) 14:30:00 +09:00 Asia/Tokyo
```

## 都市名だけの指定
```
$ wtime Tokyo
=> Asia/Tokyo として解決され、通常通りローカルタイムに加えて1行出力される
```

```
$ wtime tokyo
=> 大文字小文字を区別せず Asia/Tokyo として解決される
```

```
$ wtime "Los Angeles"
=> America/Los_Angeles として解決される（アンダースコアの代わりにスペースで指定）
```

```
$ wtime Istanbul
=> Asia/Istanbul と Europe/Istanbul の両方に一致するため曖昧な指定としてエラーになり、
   標準エラー出力に候補（Asia/Istanbul, Europe/Istanbul）を含むエラーメッセージを出力する
```

## 時間差を表示（--diff）
```
$ wtime --diff Europe/London Asia/Kolkata
2026-08-25(Tue) 14:30:00 +09:00 Asia/Tokyo (ローカル)
2026-08-25(Tue) 06:30:00 +01:00 Europe/London (-8h)
2026-08-25(Tue) 11:00:00 +05:30 Asia/Kolkata (-3h30m)
```

```
$ wtime --diff
=> --diff 指定でもタイムゾーン引数がなければ通常通りローカル時刻の1行のみ表示
```

## 基準日時を指定（--time）
```
$ wtime --time 2026-01-01T00:30:00 Europe/London
2026-01-01(Thu) 00:30:00 +09:00 Asia/Tokyo (ローカル)
2025-12-31(Wed) 15:30:00 +00:00 Europe/London
```

```
$ wtime --time "2026-08-25 14:30" --diff Europe/London
2026-08-25(Tue) 14:30:00 +09:00 Asia/Tokyo (ローカル)
2026-08-25(Tue) 06:30:00 +01:00 Europe/London (-8h)
=> 秒を省略した場合は00秒として扱う。--diff と併用すると指定日時時点のオフセットで時差を計算する
```

```
$ wtime --time 2026-08-25 Europe/London
=> 時:分を省略した日付のみの指定は不正な形式としてエラーになる
```

## ローカルタイムゾーンを変更（--set-local-tz）
```
$ wtime --set-local-tz Europe/London Asia/Tokyo
2026-08-25(Tue) 06:30:00 +01:00 Europe/London (ローカル)
2026-08-25(Tue) 14:30:00 +09:00 Asia/Tokyo
```

```
$ wtime --set-local-tz London
=> 都市名だけの指定も受け付ける（フルのIANA名 Europe/London と同様に解決される）
```

```
$ wtime --set-local-tz Europe/London --time 2026-08-25T14:30:00 --diff Asia/Tokyo
2026-08-25(Tue) 14:30:00 +01:00 Europe/London (ローカル)
2026-08-25(Tue) 22:30:00 +09:00 Asia/Tokyo (+8h)
=> --time の日時は --set-local-tz で指定したタイムゾーン（Europe/London）の壁時計時刻として解釈され、
   --diff の基準もそのタイムゾーンになる
```

```
$ wtime --set-local-tz Foo/Bar
=> 不正なタイムゾーンとして通常のタイムゾーン引数と同様にエラーになる
```

## ヘルプ・バージョン表示
```
wtime --help
=> 使いかたを表示

wtime --version
=> バージョン番号を表示
```

## 異常系
```
wtime Foo/Bar
=> 標準エラー出力にエラーメッセージを出力し、非ゼロの終了コードで終了する
```
